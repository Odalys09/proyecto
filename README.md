# Odalys Rendón Peláez — Portafolio

Sitio web personal construido con HTML5 semántico, CSS3 moderno y JavaScript vanilla.

## 🚀 Demo en vivo
[mi-portafolio.netlify.app](https://mi-portafolio.netlify.app)

## ✨ Características
- HTML5 semántico (validado en W3C)
- CSS3 con custom properties y mobile-first
- JavaScript ES6+ sin frameworks
- Menú hamburguesa, modo oscuro, smooth scroll y formulario con validación
- Accesible: skip link, foco visible y navegación completa con teclado
- Responsive desde 320px hasta 4K

## 🛠️ Tecnologías
- HTML5, CSS3 (Grid, Flexbox, custom properties)
- JavaScript ES6+ (módulos)
- Git y GitHub para control de versiones
- Lighthouse para auditoría de calidad

## ▶️ Correrlo localmente
Los módulos de JS requieren un servidor local:
```
npx serve .
```
o usa la extensión Live Server de VS Code y abre `index.html`.

Proyecto del Capítulo 1: Fundamentos del Web FullStack, del curso [Manual de Programación Junior].
